# QQ 自动加喵~ 脚本

一个在电脑端 QQ 聊天时自动在句尾加上「喵~」的 AutoHotkey 脚本。

## 功能特点

- 打字按回车后自动在句尾加上「喵~」
- 智能去除句末已有标点，避免出现「你好！喵~」
- 支持 Enter 和 Ctrl+Enter 两种 QQ 发送快捷键
- 手动开关模式，只在需要时生效，不影响正常聊天
- 后台静默运行，不干扰其他软件

## 快捷键

| 按键 | 功能 |
|------|------|
| `F7` | 开关加喵~模式（开启后托盘提示） |
| `F8` | 诊断当前窗口信息（调试用） |
| `F9` | 完全退出脚本 |

## 使用方法

### 1. 安装 AutoHotkey

下载并安装 **AutoHotkey v1.1**（必须是 v1.1 版本，不支持 v2）：
- 官网：https://www.autohotkey.com/

### 2. 运行脚本

双击 `QQ加喵.ahk` 运行，会自动申请管理员权限，点「是」即可。

脚本运行后在系统托盘区有一个绿色 H 图标。

### 3. 使用

1. 打开 QQ 聊天窗口
2. 按 `F7` 开启加喵~模式（托盘会提示「已开启」）
3. 正常打字，按回车发送，消息自动变成「xxx喵~」
4. 聊完再按 `F7` 关闭，其他好友聊天不受影响

## 注意事项

- 必须以**管理员身份**运行，否则可能无法模拟按键
- 仅支持**电脑端 QQ**（QQ.exe），不支持 TIM、QQ 轻聊版、手机 QQ
- 新版 QQ（NT 架构）窗口标题统一为「QQ」，无法自动识别特定好友，因此使用手动开关模式
- 脚本会临时操作剪贴板，发送后自动恢复原剪贴板内容

## 常见问题

**Q: 运行后没反应？**
A: 确认安装了 AutoHotkey v1.1，并且以管理员身份运行。按 F7 看托盘有没有提示。

**Q: 发送的消息没有加喵~？**
A: 确认按了 F7 开启模式（托盘提示「已开启」），并且当前窗口是 QQ 聊天窗口。

**Q: 出现「ELSE with no matching IF」报错？**
A: 下载的文件编码可能不对，确保文件是 UTF-8 带 BOM 编码。

**Q: 想改成加其他后缀？**
A: 用记事本打开脚本，搜索 `喵~`，替换成你想要的文字，保存后重新运行。
